## Описание программы:

1. #### Приложение catalog 
##### Описание:
    Содержит две веб-страницы "Главная" и «Контакты».
    Организовано переключение по соответствующим ссылкам между этими страницами.
    Для данных веб-страниц созданы контроллеры, для которых настроена маршрутизация.
    Для стилизации страниц используется Bootstrap.
    Реализована форму обратной связи на странице «Контакты».
    Настроена обработка данных формы в контроллере, чтобы отображать сообщение об 
    успешной отправке данных на странице «Контакты».
