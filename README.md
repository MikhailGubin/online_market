# Веб-приложение "Интернет - магазин"

## Описание:      
    веб-приложение, которое на любой GET-запрос возвращает страницу «Контакты».
    Также в данной программе сделанна вёрстка четырёх страниц:
    главная, каталог, категория 1, контакты.

## Описание файлов:

1. #### web_application.py 
##### Описание:
    Содержит специальный класс, который отвечает за обработку входящих запросов от клиентов.
    Так же, при запуске программы в данном файле, поднимается веб-сервер по адресу http://localhost:8080.
    Файл находится в директории src.

2. #### home.html
##### Описание:
    Содержит структуру страницы "Главная" сайта интернет - магазина.

3. #### catalog.html
##### Описание:
    Содержит структуру страницы "Каталог", содержащую в будущем информацию о всех товарах 
    сайта интернет - магазина.

4. #### category.html
##### Описание:
    В данном файле содержится структура страницы "Категория 1", на которой в будущем будет отображаться 
    информация о всех товарах выбранной категории.

5. #### contacts.html
##### Описание:
    В данном файле содержится структура страницы "Контакты", на которой в будущем будет отображаться 
    информация о контактах фирмы, которая занимается продажей товаров. Также на данной странице можно 
    остправить сообщение в фирму, заполнив форму.
